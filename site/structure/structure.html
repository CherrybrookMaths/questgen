Part levelOne main dot point decides which topic the part belongs to. Secondary dot points record other skills it uses. Style says what kind of task it is. Flags mark things a worksheet filter needs.
Why per part2022 HSC Q21 has part (a) on compound interest (Geometric sequences) and part (b) on an annuity table (Annuities). Tagged per part, a Sequences set can take (a) and a Finance set takes (b); tagged per question, one of them is always wrong.

6 · For you to decide

Six decisions before the import starts

D1Are these the right 16 teaching topics?Recommendation: keep these, matching the revision sets you asked for. Rename, merge or split freely; it costs nothing later.
D2Exactly one main tag per part?Recommendation: yes. It is what lets a set include or exclude a part cleanly (no integration, Standard course out).
D3Question styles: Find, Show/prove, Hence, Sketch/draw, Explain/justify?Recommendation: yes, five values, filled automatically from the wording and checked on a sample.
D4Flags: integration, builds on earlier part, diagram?Recommendation: yes. Each one already drove a rule you gave today.
D5Record calculator needed / not needed?Recommendation: only if you will filter by it. It is the one field that needs judgement on every part.
D6Who checks tags?Recommendation: you spot-check one topic (say Curve sketching) after the 301 are re-tagged; the rest is self-audited the way the questions were.
