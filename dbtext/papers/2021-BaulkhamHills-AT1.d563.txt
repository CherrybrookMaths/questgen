      latex: |
        Two transformations commute when applying them in either order gives the same result. Test each pair on a point $(x,y)$.

        Option C: reflection in the $y$-axis is $(x,y)\mapsto(-x,y)$ and reflection in the $x$-axis is $(x,y)\mapsto(x,-y)$.
        $$(x,y)\mapsto(-x,y)\mapsto(-x,-y) \qquad (x,y)\mapsto(x,-y)\mapsto(-x,-y)$$
        The results are the same in either order, so these commute.

        The other pairs do not commute. For a vertical reflection and a vertical translation by $k$:
        $$\text{reflect then translate: } -y+k \qquad \text{translate then reflect: } -(y+k)=-y-k$$
        For a vertical translation by $k$ and a vertical dilation by factor $2$:
        $$\text{translate then dilate: } 2(y+k) \qquad \text{dilate then translate: } 2y+k$$
        A horizontal translation and a horizontal dilation fail in the same way.

        So the correct option is C.

      For a geometric series, $S_4=\dfrac{a(1-r^4)}{1-r}=30$ and $S_\infty=\dfrac{a}{1-r}=32$.

      Cancelling $\dfrac{m}{n}$ on both sides:
      $$\begin{aligned} \dfrac{2a+(m-1)d}{2a+(n-1)d}&=\dfrac{m}{n} \\ 2an+mnd-nd&=2am+mnd-md \\ 2an-2am&=nd-md \\ 2a(n-m)&=d(n-m) \end{aligned}$$
