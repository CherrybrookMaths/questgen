      Each value has probability $P(X=x)=\dfrac1n$ for $x=1,2,\dots,n$.

      Expected value, using $1+2+\dots+n=\dfrac n2(1+n)$:

      $$\begin{aligned}E(X)&=1\times\dfrac1n+2\times\dfrac1n+\dots+n\times\dfrac1n\\&=\dfrac1n(1+2+\dots+n)\\&=\dfrac1n\cdot\dfrac n2(1+n)\\&=\dfrac{1+n}{2}\end{aligned}$$

      Using the given sum of squares:

      $$\begin{aligned}E\left(X^2\right)&=\dfrac1n\left(1^2+2^2+\dots+n^2\right)\\&=\dfrac1n\cdot\dfrac{n(n+1)(2n+1)}{6}\\&=\dfrac{(n+1)(2n+1)}{6}\end{aligned}$$
